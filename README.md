# OriginalTaskbar

Windows標準のタスクバーを非表示にして、代わりに画面上端に常駐する薄いカスタムバーを表示するWPFアプリ。

## 主な機能

### 常時表示される情報（1秒ごとに更新）
- 現在時刻（`HH:mm:ss`）
- CPU使用率
- メモリ使用率（%）
- ネットワークの受信/送信速度（KB/s・MB/s自動切替）
- バッテリー残量（充電中は🔌、放電中は🔋アイコン。デスクトップPCなどバッテリーが存在しない場合は自動的に非表示）
- 現在の仮想デスクトップ番号（`Desktop1`, `Desktop2`...）

### 実行中アプリ一覧
- **現在の仮想デスクトップに存在するウィンドウだけ**をアイコン付きで一覧表示（他デスクトップのウィンドウは含まない）
- クリックでそのウィンドウをフォアグラウンド化（最小化中なら復元）
- 表示順はZオーダー（フォーカス順）に引きずられず、初めて検出した順を維持
- 列挙・アイコン取得はバックグラウンドスレッドで実行し、UIスレッド（時計など）をブロックしない

### タスクバー制御
- 起動時にWindows標準のタスクバーを完全非表示（`ShowWindow(SW_HIDE)`）
- Winキー押下をグローバルフックで検知し、標準タスクバーを一時的に再表示（Start画面やWin+Xなどが正常に使えるように）。一定時間操作がなければ再び非表示に戻る
- アプリ終了時（正常終了）には必ずタスクバーを復元。強制終了（`taskkill /F`など）の場合はOS上プロセス内コードを実行できないため復元できない。その場合はタスクマネージャー→「新しいタスクの実行」→`explorer.exe`で復旧

### 画面レイアウトへの統合
- `SHAppBarMessage`（AppBar API）でOSの作業領域を予約。最大化したウィンドウがバーの下に潜り込まず、重ならない
- 仮想デスクトップへのピン留め（`Slions.VirtualDesktop`経由）により、このバー自体はどの仮想デスクトップに切り替えても常に表示され続ける

### カスタマイズ
- バーを右クリックすると、各項目（時計・CPU・メモリ・ネットワーク・バッテリー・仮想デスクトップ番号・実行中アプリ一覧）の表示/非表示をチェックボックスで切り替え可能
- 設定は`%AppData%\OriginalTaskbar\settings.json`に保存され、再起動後も維持される

## プロジェクト構成

| ファイル | 役割 |
|---|---|
| `MainWindow.xaml` / `.cs` | バー本体のUIとロジック。各種タイマー・イベントの配線 |
| `App.xaml` / `.cs` | アプリ全体の起動処理、未処理例外時のタスクバー復元 |
| `NativeMethods.cs` | Win32 API（`user32`/`kernel32`/`dwmapi`）のP/Invoke宣言 |
| `TaskbarService.cs` | 標準タスクバー（`Shell_TrayWnd`等）の表示/非表示制御 |
| `LowLevelKeyboardHook.cs` | Winキー押下を検知するグローバルキーボードフック |
| `AppBarService.cs` | `SHAppBarMessage`によるワークエリア予約 |
| `RunningAppsService.cs` | 実行中ウィンドウの列挙・仮想デスクトップ判定・アイコン取得 |
| `AppSettings.cs` | 表示/非表示設定の読み書き（JSON） |
| `Log.cs` | ファイルベースの診断ログ（既定で無効。`Enabled`フラグで切替） |

## 依存パッケージ

- [`Slions.VirtualDesktop` / `Slions.VirtualDesktop.WPF`](https://github.com/Slion/VirtualDesktop)（`Grabacr07/VirtualDesktop`のフォーク。より新しいWindowsビルドに追従）
- `System.Drawing.Common`（実行ファイルからのアイコン抽出フォールバック用）

## ビルド・実行

```
dotnet build
dotnet run
```

- .NET 8 SDK、Windows 10 build 19041（20H1）以降が必要
- **管理者権限のターミナルからは実行しないこと**。Explorerは通常非管理者で動作しており、権限が異なるとシェルの仮想デスクトップCOM APIの呼び出しが軒並み失敗する

## 既知の制約

- 仮想デスクトップのピン留め・現在デスクトップ判定は非公開のシェルCOM APIに依存しており、将来のWindows Updateで動作しなくなる可能性がある
- フォントは`BIZ UDPゴシック`（Windows 11に標準搭載）を前提としている
- 強制終了時のタスクバー復元は原理的に不可能（上記参照）
